Anchor

A focus companion that knows when you drift — and knows when to leave you alone.

— the Anchor team
01 — Problem Statement

You didn't get distracted. Your tools just can't tell the difference.

To-do lists count tasks. Timers count minutes. Blockers count domains. None of them read the page.

Starting

A big, vague task sits there for hours — not because you're lazy, because you can't find the first move.

Drifting

You're working. Then, without deciding to, you're on YouTube. You don't notice until it's cost you twenty minutes.

Anchor is the first tool that actually reads what's on your screen and judges it against what you said you'd do — not another timer, not another blocklist.

02 — Solution Overview

One rule: judge relevance by what's actually on the page — never by domain, never by tab count.

Starter Coach

Turns a vague task into one absurdly small first action. You're physically moving inside two minutes.

Focus Companion

Watches quietly. Speaks up only when it's genuinely confident you've drifted.

It knows the difference between researching and doomscrolling
03 — Target Users

Anyone who's ever opened one tab and lost an hour.

Builders & coders

Deep in a flow across an IDE, docs, and an AI chat. Anchor learns that rhythm, and only interrupts when the flow actually breaks.

Researchers & students

Long stretches of quiet reading. Anchor treats stillness as focus, not a problem to flag.

Course & lecture watchers

Hours of video as the task itself. Anchor catches the moment a lecture becomes background noise.

Built first for people who find starting and staying the hardest — including ADHD — and just as useful for anyone else who's opened one tab and lost an hour.

04 — Product Features

Four moving parts. One loop.

Starter Coach

Turns a vague task into one small first action, so you're moving inside two minutes.

Drift check-in

Triggers when you've left the task and haven't come back.

  • Still on track — false alarm
  • This counts as work — whitelists the page
  • Drifted — pull me back — switches your tab back
Stuck check-in

Triggers when you're still on the right page, but nothing's moved in 15 minutes.

  • Deep in thought — confirms you're fine
  • Drifted — pull me back — resets the pace
Rest & summary

Take a break silences everything until you're ready. Done for today closes the loop with what actually happened.

05 — Technical Architecture

Two layers, one contract.

Perception and decision live in pure TypeScript; only the platform layer touches Chrome. One typed contract crosses the seam.

Four signals, evaluated together

Context

Is this page's content actually about the task — judged by an LLM, cached per page.

Anchor

How long it's been since you last touched a page the LLM judged relevant.

Texture

Whether your input right now is purposeful, passive scrolling, or idle.

Jump

Whether you're orbiting relevant tabs or falling down a rabbit hole of unrelated ones.

Built for real MV3 constraints

Service-worker sleep

Chrome kills the background script when idle — timestamps are persisted and rehydrated, never held only in memory.

Shadow DOM injection

The pet renders in a shadow root, so the host page's CSS can never leak in — and ours can never leak out.

06 — AI Technologies Used

Right-sized intelligence — not the same hammer twice.

Relevance classifier

gpt-oss-20b

One quick judgment: is this page actually about the task?

Runs on every page you open — fast, cheap, decisive. Same page, same answer, every time.

Starter coach

gpt-oss-120b

Turns a vague task into one small first action, and writes every check-in like a friend would.

Runs rarely — once per task, once per check-in. The budget goes to thinking harder, not answering faster.

The right model for the job, every time

Served through Groq's OpenAI-compatible API — open-weight models, prompt-engineered for the job, no fine-tuning, no training on your data.
